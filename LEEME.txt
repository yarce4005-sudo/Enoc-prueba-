# ENOC Admin para iPhone (PWA)

## Contenido
- `admin.html`: administrador ENOC corregido, conserva las mejoras de imágenes y el registro push mediante Supabase.
- `admin.webmanifest`: configuración de instalación como app.
- `sw.js`: service worker, recepción Web Push y apertura del administrador al tocar una notificación.
- `icons/`: iconos proporcionados para iPhone y PWA.

## Publicación
1. Haz una copia de seguridad de los archivos actuales.
2. Publica `admin.html`, `admin.webmanifest`, `sw.js` y la carpeta `icons/` en la misma carpeta/ruta del administrador.
3. Mantén el sitio bajo HTTPS.
4. No cambies las credenciales ni las variables de Supabase del administrador.
5. En iPhone, abre la URL del administrador en Safari → Compartir → Añadir a pantalla de inicio.
6. Abre ENOC desde el icono instalado, inicia sesión como administrador y pulsa Activar notificaciones.

## Estado de notificaciones
El administrador obtiene la clave pública VAPID y registra la suscripción mediante:
`/functions/v1/enoc-push-subscribe`

Este paquete prepara el cliente para registrar el dispositivo y recibir mensajes Web Push. **No incluye ni despliega el servicio servidor que debe enviar el mensaje cuando se crea un pedido/venta.** Ese servicio debe existir y usar las suscripciones guardadas en Supabase junto con las claves privadas VAPID. Hasta probar ese envío real, no se debe considerar validada la notificación automática de ventas.

## Seguridad y datos
El service worker no almacena en caché páginas autenticadas, sesiones, API ni datos privados. La base de datos sigue siendo Supabase. No se incluye ninguna clave secreta nueva.
